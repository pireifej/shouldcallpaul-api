---
name: Workshop resource ownership
description: Private working-material shortcuts are shared across the presentations of a CRM engagement.
---

Treat resource shortcuts as private working materials for the CRM engagement,
not as public presentation attachments.

**Why:** The owner expects multiple résumé presentations associated with one
workshop engagement to share the same Notes, Outline, PowerPoint and Handouts
shortcuts. A separate resource set per presentation would create duplicate work
and could accidentally expose private preparation materials on the public site.

**How to apply:** Preserve one shared set when linking or unlinking public
presentations, and do not infer that a resource should be public because the
associated résumé entry is published.
